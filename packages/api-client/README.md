# @bella/api-client

Generated from the API's OpenAPI schema. **Never hand-edit anything in this package.**

```bash
make openapi   # writes openapi.json from the running FastAPI app
```

A hand-maintained client is how request and response types drift away from the server.
Regenerating is a build step, not a chore.

Populated in Phase 3, once the endpoint contract in
[docs/05-api-contract.md](../../docs/05-api-contract.md) is stable.
